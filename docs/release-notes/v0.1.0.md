**First public pre-alpha of XDeck**, an Xbox 360-style Game Pass dashboard for
the Steam Deck. It's an early work in progress: expect bugs, and please
report them in Issues.

## Install (Steam Deck, Desktop Mode)

1. Download **`XDeck-0.1.0-x86_64.AppImage`** below. It's the only file you
   need. (Not a `.dmg`: that's macOS. AppImage is the Linux equivalent.)
2. In Dolphin, right-click it > **Properties** > **Permissions** > tick
   **Is executable**.
3. Double-click it. XDeck offers to **install** itself: it copies itself to
   `~/Applications`, sets up umu-launcher, uses the Xbox app icon and adds
   itself to Steam. No password needed.
4. Switch to **Gaming Mode**, open XDeck from your library, and set its
   controller layout to **Gamepad**.

Prefer a terminal? Run `chmod +x XDeck-0.1.0-x86_64.AppImage && ./XDeck-0.1.0-x86_64.AppImage --install`.

## What's in 0.1.0

- Xbox 360-style dashboard with lowercase sections and scrolling tiles,
  fully controller-driven
- **Cloud games:** the full Xbox Cloud Gaming catalog, streamed in-app.
  Cloud-only titles are labelled and filterable (needs Game Pass Ultimate)
- **PC Game Pass:** the whole PC catalog, with badges showing how each
  game can be played on the Deck
- **Import:** bring games installed on Windows (with "advanced management
  features" on) onto the Deck from USB, SD, a dual-boot Windows partition
  or a network share. Imports are verified and can be resumed.
- **My games:** launch through Proton/umu, pick a Proton version per game,
  or add any game to Steam as its own shortcut
- **Profile:** gamertag, gamerscore and achievements via a free
  [OpenXBL](https://xbl.io) key
- Stability: capped logs, games always stopped on exit, bounded memory
  for catalog art, single instance

## Known limitations

- The Windows Xbox app itself can't run on Linux, and XDeck can't download
  Game Pass PC games directly. Both need Microsoft's Gaming Services.
- Many first-party Game Pass PC titles check their licence through Gaming
  Services and won't start under Proton. Cloud streaming works for those.
- Tested with automated tests and in a desktop Linux environment. This is
  its first outing on real Steam Deck hardware.
